포터블 실행 방법

서명되지 않은 포터블

Windows 설정의 시스템 → 정보 → 시스템 종류에서 PC 아키텍처를 확인하고 알맞은 ZIP을 받으세요. ZIP 전체를 폴더에 풀고 OpenGeul.exe를 실행하세요. 포함된 파일과 폴더를 함께 보관하고, 해당 PC용 WebView2 런타임을 설치하세요.

포터블 파일에는 신뢰된 코드 서명이 없습니다. Windows와 조직의 보안 정책에 따라 실행이 제한될 수 있습니다.

사용 안내

작업을 시작하기 전에
확인해 주세요.

이 안내는 포터블 v1.1.4 기준입니다.

Windows와 WebView2
x64 포터블은 Windows 10 버전 2004 이상 또는 Windows 11의 x64 환경을 지원합니다. ARM64 포터블은 Windows 11의 ARM64 환경을 지원합니다. 두 버전 모두 WebView2 런타임이 필요합니다. 32비트 전용 빌드는 제공하지 않습니다.
원본과 글꼴
문서의 모든 요소가 원본과 똑같이 표시되거나 저장된다고 보장하지 않습니다. 설치된 글꼴이 다르면 배치가 달라질 수 있습니다. 원본을 보관하고 저장·인쇄 결과를 확인하세요. 글꼴 파일은 함께 배포하지 않습니다.
현재 기능 범위
인터페이스는 한국어를 우선합니다. 자동 저장과 복구는 지원하지 않습니다. DOCX·XLSX·PPTX와 LibreOffice 연동도 포함하지 않습니다.
암호 문서
지원되는 암호 HWP/HWPX 문서를 암호를 입력해 열 수 있습니다. 잘못 입력하면 다시 입력하거나 취소할 수 있습니다. 암호 문서의 일반 저장은 차단되며, 다른 이름으로 저장할 때 암호 없는 HWP/HWPX 파일을 만들기 전에 확인합니다. 확인을 취소하면 평문 파일을 만들지 않습니다. 원본 암호 문서를 보관하려면 원본과 다른 경로를 선택하세요. 문서에 암호를 유지하거나 새로 설정하여 저장하는 기능은 제공하지 않습니다.
새 버전 알림
기본으로 앱 시작 시와 실행 중 매시간 Microsoft Store 공개 버전을 확인합니다. 파일 메뉴의 Store 업데이트 자동 확인에서 끄거나 Store 업데이트 확인으로 직접 확인할 수 있습니다. 새 버전 안내에서 Microsoft Store 열기를 선택하면 Store에서 업데이트를 진행할 수 있습니다. 나중에를 선택하면 해당 버전의 자동 알림을 숨깁니다.
PC에 보관하는 정보
선택한 문서는 PC에서 처리합니다. 1.1.4에는 사용량 분석용 텔레메트리가 포함되지 않습니다. 최근 문서 목록과 사용자가 직접 저장한 문서 이력은 로컬에 남을 수 있습니다. 보관 항목과 삭제 방법은 개인정보 처리방침에서 확인하세요.
