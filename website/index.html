사용 안내

작업을 시작하기 전에
확인해 주세요.

이 안내는 1.1.2 개발판 기준입니다.

Windows와 WebView2
Windows 10 버전 2004 이상 또는 Windows 11의 x64 환경을 지원합니다. WebView2 런타임이 필요합니다. ARM64와 32비트 전용 빌드는 제공하지 않습니다.
원본과 글꼴
문서의 모든 요소가 원본과 똑같이 표시되거나 저장된다고 보장하지 않습니다. 설치된 글꼴이 다르면 배치가 달라질 수 있습니다. 원본을 보관하고 저장·인쇄 결과를 확인하세요. 글꼴 파일은 함께 배포하지 않습니다.
현재 기능 범위
인터페이스는 주로 한국어입니다. 자동 저장과 복구는 지원하지 않습니다. DOCX·XLSX·PPTX와 LibreOffice 연동도 포함하지 않습니다.
암호 문서
지원되는 암호 HWP/HWPX 문서를 암호를 입력해 열 수 있습니다. 잘못 입력하면 다시 입력하거나 취소할 수 있습니다. 암호 문서의 일반 저장은 차단되며, 다른 이름으로 저장할 때 암호 없는 HWP/HWPX 파일을 만들기 전에 확인합니다. 확인을 취소하면 평문 파일을 만들지 않습니다. 원본 암호 문서를 보관하려면 원본과 다른 경로를 선택하세요. 문서에 암호를 유지하거나 새로 설정하여 저장하는 기능은 제공하지 않습니다.
PC에 보관하는 정보
선택한 문서는 PC에서 처리합니다. 최근 문서 목록과 사용자가 직접 저장한 문서 이력은 로컬에 남을 수 있습니다. 보관 항목과 삭제 방법은 개인정보 처리방침에서 확인하세요.
