# OpenGeul 1.1.5 — 기능 검증 후보

비동기 붙여넣기, 그림 파일 배치와 설치 글꼴 선택 중 문서·선택이 바뀌면 잘못된 대상이 수정되던 문제를 고쳤습니다. 메뉴 붙여넣기와 일반 텍스트의 실행 취소, GUI PDF의 검색 문자 누락도 수정했습니다. Windows x64와 ARM64의 네이티브 편집기·CLI, 고정 HOP 0.4.5·rhwp 0.8.7, 설치된 글꼴만 사용하는 정책을 유지합니다.

## 수정한 기능

- 이미지·RTF 붙여넣기는 시작한 문서와 편집 문맥을 확인합니다. 문서 교체·닫기·선택 변경·편집 후 늦게 끝난 작업을 취소하고, 정상 붙여넣기와 한 번의 실행 취소·다시 실행을 유지합니다. 셀·그림·표 선택을 옮겼다가 되돌리는 경우도 취소하며, 이전 편집의 지연된 페이지 계산만 끝난 경우에는 정상 붙여넣기를 허용합니다.
- 그림 파일 선택·읽기·해독과 배치는 원래 문서와 입력 처리기의 수명에 연결합니다. 문서 교체·종료 때 배치 데이터·드래그·겹침 화면·이벤트를 정리합니다. 같은 문서에서 실제 클릭 위치에 그림을 놓는 동작은 유지합니다.
- 글상자·일반 도형·다각형·연결선 생성이 실행 취소 기록에 빠지던 문제를 고쳤습니다. 생성·실행 취소·다시 실행과 연결 대상·기하를 보존하며, 문서를 바꾸거나 창을 비활성화·종료하면 대기 중인 배치와 표시를 해제합니다.
- 설치 글꼴을 읽는 동안 선택·문서·편집 문맥·언어가 바뀌면 다른 대상에 서식이나 글꼴 ID를 추가하지 않습니다. 대표 글꼴 세트, 최신 요청, 정상 서식 적용·실행 취소·저장·재열기를 유지합니다.
- 메뉴 붙여넣기에서 실제 붙여넣기 이벤트가 들어오지 않으면 시스템 클립보드의 텍스트·서식·그림을 읽어 기존 붙여넣기 처리로 연결합니다. 정상 이벤트가 들어온 경우 중복해서 붙이지 않습니다. 선택한 일반 텍스트와 여러 줄은 한 번에 실행 취소하고, 이전 입력·입력 필드 경계를 보존합니다. 빈 클립보드는 선택 내용을 지우지 않습니다.
- GUI PDF에서 눈에 보이는 좁은 라틴 문자·숫자가 PDFium 검색·복사에서 빠지거나 불필요한 공백이 생기는 문제를 고쳤습니다. 기존 중첩 SVG와 글꼴 포함 권한 검사를 유지합니다. [좌표 변환 검증과 렌더 비교](GUI_PDF_SEARCH_TEXT.md)에 실제 확인한 결과와 새 Windows 검증의 범위를 기록했습니다.
- MCP의 공개 세션·작업 공간 열기, 읽기, 편집, 저장, 닫기, 닫힌 문서 오류와 작업 기록을 필수 검증에 추가했습니다. 무상태 파일 작업의 별도 COM 작업자와 실패 격리를 유지합니다. 세션·작업 공간 도구는 MCP 서버에서 실행합니다.
- MCP 검사 자료 준비 오류에 고정 단계·오류 코드와 제한된 숫자 정보만 기록합니다. 인증 정보·응답 본문·URL·예외 문자열은 출력하지 않으며, 기존 제한·실패 처리·출력 보존을 유지합니다.

## 후보 검증

기존 열기·편집·저장·암호·변환·창·인쇄 검사를 유지합니다. 표·그림·찾기·서식과 Windows 클립보드·설치 글꼴·최근 문서·실제 끌어놓기·파일 메뉴의 PDF 내보내기를 추가해 브라우저 21개, 네이티브 42개 사례를 요구합니다. 문서 최초 저장·여러 창·실제 외부 HTML·그림 클립보드·Windows 한국어 IME와 고급 편집의 저장·실행 취소·재열기도 포함합니다. PDF 내보내기와 인쇄 PDF는 각각 검사합니다. 기존 MCP 33개와 함께 구조 문서의 유효 CLI·MCP 16개를 별도로 요구하며, COM 작업자 실패 격리는 기존 필수 검사에서 확인합니다.

현재는 후보 준비 단계입니다. 새 클립보드 처리의 실제 문서 엔진·저장·실행 취소와 TypeScript 검사를 통과했고, 새 GUI PDF 변환의 네이티브 SVG 정책 검사와 검색 텍스트도 확인했습니다. 실제 Windows x64·ARM64, 브라우저 3종, 설치·MCP·인쇄와 양쪽 필수·선택 WACK의 새 전체 실행 결과는 확인 중입니다. 로컬 단위·문서 엔진 검사를 실제 Windows 실행이나 Store 인증으로 표시하지 않습니다.

## 배포와 고지

Microsoft Store 접수·인증·공개는 각각 실제 API 상태로 확인합니다. 이 후보 준비는 Store 공개 완료를 뜻하지 않습니다. 무료 가격과 인증 후 즉시 자동 공개 조건, 이전 제출 보호를 유지합니다.

Telemetry는 이번 후보에 포함하지 않습니다. WebView 없이 동작하는 Windows 화면은 별도 연구 단계입니다. GUI PDF는 SVG 호환 경로와 검색 가능한 텍스트를 사용하며, 직접 Skia PDF는 글꼴 포함 권한 필터를 적용하기 전까지 차단합니다.

자체 코드는 MIT이며 업스트림·제3자 라이선스 고지를 유지합니다. [1.1.4 릴리스 기록](releases/1.1.4.md)의 정규 태그·공개 자산·당시 검증 결과는 보존했습니다.
