# 업스트림 표 높이 검증

이 통합의 대상은 HOP 0.4.5가 사용하는 rhwp 0.8.7, 커밋 `1a76570e833917d15817415a53c09ad61ab3203f`입니다. 엔진은 PR 6076을 통해 통합된 rhwp PR 6074의 마지막 음수 간격 수정(`c7d3c66398acdb3c093fdea6fef573e14f771a6c`, planet6897)을 이미 포함합니다. 중복 다운스트림 소스 패치와 그 패치 기록 요구는 제거했습니다. 소스 출처는 정확한 업스트림 잠금값에 계속 연결됩니다. HOP #99/#78과 관련 있지만 해당 제보가 해결됐다는 증명은 아닙니다. 원래 #99 첨부 자료가 없고 인쇄 드라이버 동작은 별도 테스트 대상입니다.

이전 고정 엔진의 과거 RED 근거는 PR2 실행 37391710620에서 소스를 검증한 WASM 산출물 11381666392를 사용합니다. 5문단 합성 HWPX 표는 줄 높이 1000-HWPUNIT, 간격 -300-HWPUNIT, 위·아래 여백 각각 141-HWPUNIT을 사용하고 선언 높이를 줄이는 추정 규칙은 없습니다. 마지막 그려진 줄이 셀 경계를 2.2px 넘었고, 셀 높이는 54.4px 대신 50.4px였습니다. 당시 0·양수 간격 대조군은 70.4px/110.4px였습니다. 원래 정상 단언이 실패했고 음성 대조 실행에서도 해당 잘림을 재현했습니다.

수정하지 않은 rhwp 0.8.7 WASM은 열기·HWPX 재열기 형태 검사 6개를 모두 통과했습니다. -300/0/+600-HWPUNIT 간격에서 셀 높이는 54.4/70.4/102.4px이며 넘침은 각각 -1.8px로 마지막 줄이 안에 들어옵니다. 모든 사례는 계속 줄 5개, 예상 텍스트 각각 정확히 한 번과 원래 줄 사이 간격을 요구합니다. 새 엔진은 높이 측정 두 지점(`height_measurer.rs` 3180–3205행과 4161–4183행)에서 비어 있지 않은 마지막 줄 뒤 간격을 제외합니다. 따라서 독립 판정식은 글리프 높이 5개, 사이 간격 4개와 여백 282-HWPUNIT의 합인 `(5*1000 + 4*spacing + 282)*96/7200`입니다. +600 대조군은 이전 다운스트림 백포트보다 의도적으로 8px 짧으며, 사이 간격 4개는 양수로 그대로 유지됩니다. 이 식은 업스트림의 공백·RowBreak 예외나 임의의 표 전체를 다루지 않습니다.

수정하지 않은 벤더 WASM은 11,803,733바이트이고 SHA-256은 `5a77a0f5156c7fbf6db1745095d7886d057b5d05bfba25759112cb46be8e97ec`입니다. 원래 `PROVENANCE.json`이 정확한 0.8.7 커밋을 가리키며 해시가 검사한 바이트와 일치합니다. 로컬 근거는 `.work/upgrade-evidence/pristine-wasm.json`과 `pristine-table-green.json`에 보존합니다. 같은 테스트 자료 검증기를 수정하지 않은 WASM과 소스 재빌드 WASM 모두에 실행합니다. 네이티브 Rust 형태 검사, 소스 재빌드 WASM과 모든 릴리스 UI·인쇄 검증은 계속 필수입니다. 벤더 WASM 통과가 이 검증들까지 통과했음을 입증하지는 않습니다.

기존 브라우저·네이티브 UI 실행 62회와 MSIX 설치 검사는 유지합니다. 합성 테스트 자료는 실행기에서 생성하고 고객 문서를 사용하지 않습니다. 글꼴 프로그램을 추가하지 않습니다. 형태 검증은 한컴과 완전히 일치하는 픽셀 기준이나 물리 프린터 테스트가 아닙니다.
