# Upstream table-height verification

Current target: rhwp 0.8.7, commit `1a76570e833917d15817415a53c09ad61ab3203f`, consumed by HOP 0.4.5. The engine already incorporates the terminal-negative-trailing fix from rhwp PR 6074 (`c7d3c66398acdb3c093fdea6fef573e14f771a6c`, planet6897), integrated through PR 6076. The duplicate downstream source patch and its patch-ledger requirement are removed. Source provenance remains bound to the exact upstream lock. This is related to HOP #99/#78 but is not proof those exact reports are resolved. The original #99 attachment is not present, and print-driver behavior is a separate test target.

Historical RED evidence from the earlier pinned engine uses source-verified WASM artifact 11381666392 from PR2 run 37391710620. A five-paragraph synthetic HWPX table has 1000-HWPUNIT lines, -300-HWPUNIT spacing, 141-HWPUNIT top/bottom padding, and no declared-height shrink heuristic. The last painted line exceeds the cell box by 2.2px; cell height is 50.4px instead of 54.4px. Earlier zero/positive controls were 70.4px/110.4px. The original normal assertion failed and its negative-control runner reproduced that specific clipping.

Pristine rhwp 0.8.7 WASM now passes all six opened/HWPX-reopened geometry cases: -300/0/+600-HWPUNIT spacing gives 54.4/70.4/102.4px cell heights, each with -1.8px overflow (the last line fits). Every case still requires five lines, exactly one copy of each expected text and the original between-line pitch. The newer engine excludes trailing spacing after a nonblank terminal line at both height-measurement sites (`height_measurer.rs` lines 3180–3205 and 4161–4183). Thus the independent oracle is five glyph heights plus four spacing gaps and 282-HWPUNIT padding: `(5*1000 + 4*spacing + 282)*96/7200`. The +600 control is intentionally 8px shorter than the earlier downstream backport; its four gaps remain positive and unchanged. This formula does not cover the upstream whitespace/RowBreak exception or arbitrary tables.

The pristine vendor WASM is 11,803,733 bytes, SHA-256 `5a77a0f5156c7fbf6db1745095d7886d057b5d05bfba25759112cb46be8e97ec`; its original `PROVENANCE.json` names the exact 0.8.7 commit and its hash matches the bytes tested. Local evidence is retained in `.work/upgrade-evidence/pristine-wasm.json` and `pristine-table-green.json`. The same fixture validator runs on both pristine and source-rebuilt WASM. Native Rust geometry, source-rebuilt WASM and all release UI/printing gates remain required; a pristine vendor PASS does not establish that those gates passed.

Existing 62 browser/native UI executions and MSIX installation checks remain enabled. Synthetic fixtures are generated in the runner, never taken from customer documents. No font programs are added. Geometry verification is not a full Hancom pixel-golden or a physical-printer test.
