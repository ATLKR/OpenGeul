# HWPX save and free-runner E2E

The requested product remains an installed-font-only Windows HWP/HWPX editor using pinned MIT HOP/rhwp sources. Add genuine HWPX serialization of edited WASM state, native staged persistence with revision/external-change guards, and format-aware Save As. Retain existing HWP paths and checks; do not implement saving by renaming HWP bytes or re-reading the unedited source.

Tests must operate on generated synthetic documents, production portable/MSIX binaries, and the production browser frontend. No customer documents, font programs, test IPC backdoors, or secrets are shipped. Browser capability emulation is labeled separately from native Windows dialogs. A separate ZIP/XML oracle checks semantic output without invoking rhwp.

Target standard free public GitHub runners only: Windows 2025/2022 and Ubuntu 24.04 with Chromium/Firefox/WebKit. Required tests must gate publication; failures retain bounded logs, traces, screenshots and machine-readable reports. Actual OS IME, printers, Hancom fidelity and Store certification remain distinct from simulated keyboard events and automated structural checks.

Implementation candidates require actual CI evidence before merge/release. The previous v1.0.0 build does not verify these new changes.
