# HWPX 저장과 무료 실행기 E2E 사양

> 이 문서는 2026-10-05 당시의 요청과 검증 요구사항을 보존한 사양입니다. 후속 후보의 구현·검증 완료를 선언하지 않습니다.

요청한 제품은 고정된 MIT HOP/rhwp 소스를 사용하며 설치된 글꼴만 사용하는 Windows HWP/HWPX 편집기다. 편집된 WASM 상태를 실제 HWPX로 직렬화하고, 리비전·외부 변경 가드가 있는 네이티브 임시 저장과 형식을 구분하는 다른 이름으로 저장을 추가한다. 기존 HWP 경로와 검사를 유지한다. HWP 바이트의 파일 이름만 바꾸거나 편집 전 원본을 다시 읽는 방식으로 저장을 구현하지 않는다.

테스트는 생성한 합성 문서, 프로덕션 portable/MSIX 바이너리와 프로덕션 브라우저 프런트엔드에서 동작해야 한다. 고객 문서, 글꼴 프로그램, 테스트용 IPC 우회 경로나 비밀 정보를 배포하지 않는다. 브라우저 기능 에뮬레이션은 네이티브 Windows 대화상자와 별도로 표시한다. 별도의 ZIP/XML 검증기는 rhwp를 호출하지 않고 출력 의미를 확인한다.

공개 GitHub의 무료 표준 실행기만 대상으로 한다. Windows 2025/2022와 Chromium/Firefox/WebKit을 사용하는 Ubuntu 24.04다. 필수 테스트가 게시 여부를 결정해야 하며, 실패하면 크기가 제한된 로그·추적·스크린샷·기계 판독 가능한 보고서를 보존한다. 실제 OS IME, 프린터, 한컴과의 재현 충실도와 Store 인증은 키보드 이벤트 시뮬레이션이나 자동 구조 검사와 구분한다.

구현 후보는 병합·릴리스 전에 실제 CI 증거가 필요하다. 이전 v1.0.0 빌드는 이 새 변경을 검증하지 않는다.
