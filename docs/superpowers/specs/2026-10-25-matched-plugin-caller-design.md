## Approach and limits

Use the existing system DbgHelp adapter and owned suspended-process Job helper.
Resolve local verified PDB data outside editor hooks. A fixed-name round-trip
qualification of WinSalYieldMutex::doAcquire (SymFromName then exact containing
function/address/range round-trip with SymFromAddr) must pass before GUI preparation;
this checks actual native symbol support, not a runtime caller. No symbol
enumeration, remote search or fallback is permitted. Each isolated symbol
operation shares one original 30-second deadline, with 27 seconds for work and
three seconds reserved for cleanup; child deadlines inherit finite parent
monotonic values. Startup, imports, reads and hashes consume that same deadline.
Failure of qualification stops this experiment before editor execution.

The loaded backend may be documented SymPdb (3) or SymDia (7); neither permits
relaxing the exact loaded PDB path, GUID/age, base, image size or unmatched flags,
and the fixed-function round trip remains mandatory. Other symbol types fail.
An identity failure retains only a seven-bit mismatch mask (type, base, size,
GUID, age, unmatched, path) and the bounded symbol type 0–8 (9 means unknown).
This uses the existing child exit-code channel, no additional native query or
raw field output. Run40198528845 established composite metadata rejection but
did not establish which field differed; SymDia compatibility is not yet a
confirmed explanation of that native failure.

## Interpretation checks

The selector joins every selected stack's PID, thread, HWND and engine creation
time to the original keyboard/observer admission. It joins the held plugin's
SHA-256 and RSDS identity to the offline resolver's independently verified pair.
Terminal-copy QPC coverage is reported as covered, truncated or unknown,
separately from a producer callback's expiry flag. Unresolved symbols retain their
receipt and produce an inconclusive outcome. A completed query is not a caller
classification, and a recognized function is not proof of causal responsibility.
