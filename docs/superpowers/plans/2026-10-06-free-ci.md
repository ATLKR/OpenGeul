# 무료 실행기 CI와 네이티브 대화상자 후속 작업

> 이 문서는 2026-10-06 당시의 계획, 검증 지점과 동시 변경 조정 기록입니다. 아래의 최신·현재·최종 표현은 당시 작업 맥락을 가리킵니다.
> 테스트 주도 개발로 같은 세션에서 실행한다.

**목표:** 공개 표준 실행기만 사용하고, 단계별 피드백과 제한된 저장 공간을 제공하면서 릴리스 안전성을 유지한다.
**구조:** 전체 실행마다 WASM 빌드 하나와 Windows 빌드 하나를 유지한다. 같은 실행의 아티팩트를 기존 UI·인쇄·설치 작업에서 공유한다. 비용이 낮은 사전 검사 의존성과 게시하지 않는 명시적인 수동 engine 전용 모드를 추가한다.
**사양:** OpenGeul을 개선하고 유료 실행기 없이 무료 CI를 최대한 활용해 달라는 사용자 요청.

## 제약과 검토

- ubuntu-24.04, windows-2022, windows-2025만 사용한다. 비공개 저장소 실행, 더 큰 실행기·자체 호스팅·사용자 지정 이미지 작업, 유료 서비스 액션, 자동 캐시 또는 LFS를 사용하지 않는다.
- 전체 push/PR/tag 빌드에서 편집기 UI 62개, 가상 인쇄 시나리오 16개와 설치 테스트를 유지한다. 수동 engine 모드는 게시할 수 없다.
- 성공 요약은 로그와 작업 요약에 남긴다. 업로드하는 성공 증거는 1 MiB, 실패 증거는 12 MiB로 제한하고 글꼴·개인 키는 제외한다. 누락 항목을 모두 기록하며, 실패한 테스트를 통과로 바꾸지 않는다.
- 전송 아티팩트는 하루 보관한다. 다른 실행이나 당시의 진단 증거를 삭제하지 않는다. 같은 실행의 출처 정보를 유지하고 빌드 입력이 크기 제한을 넘으면 실패 처리한다.
- 작업 분할 전략은 GitHub 요금이나 계정 예산보다 우선하지 않는다. 실제 지출 0 강제는 소유자가 설정하는 $0 사용 중단 예산에 달려 있다.

## 작업

- [x] 실행기·설정 정책 검사와 단계별 full/engine 워크플로를 RED/GREEN으로 검증한다.
- [x] 증거 가지치기, 업로드 바이트 상한과 요약 집계를 RED/GREEN으로 검증한다.
- [x] 손상 파일 CI 추적에서 확인된 네이티브 파일 대화상자 선택자 재바인딩 문제를 메시지 검사를 우회하지 않고 수정한다.
- [ ] 모든 변경 파일이 당시 원격 원본과 일치하는지 확인한다. 로컬 테스트와 새 GitHub CI를 실행하고, 인쇄 필수 검사가 실패한 상태에서는 병합하지 않는다.

## 소스 경계

검증된 로컬 스냅샷은 0999cf2가 아니라 adcf128(a0f1366에 진단 워크플로를 추가한 상태)이었다. 수정 전, 변경하지 않은 워크플로와 드라이버의 blob 해시를 원격 0999cf2와 대조했다. 원격 헤드 위에 명시적으로 변경한 파일만 커밋하고, 원격의 추가 보강 파일은 보존한다. 로컬 기준은 테스트 75개이며, 이를 더 새로운 브랜치의 전체 테스트 121개라고 보고하지 않는다.

## 검증 지점

- 새 정책·증거 테스트 28개는 구현 전에 실패했고 구현 후 통과했다. 추가 워크플로 연결 검사 5개도 처음에는 실패했으며, 통합 후에는 6개 모두 통과했다. 네이티브 선택자 테스트 4개는 바인딩 추가 전에 실패했다. 실패 사례 증거 우선순위도 우선순위 정렬을 구현하기 전에 실패했다.
- 당시 최종 로컬 테스트 묶음: CI 테스트 36개, 기준·네이티브 테스트 79개(기존 75개 + 새 4개). 모든 워크플로 YAML은 중복 키를 거부하며 파싱했고 허용 목록 감사를 통과했다.
- 실제 이전 네이티브 아티팩트로 패커를 테스트했다. 원본은 13,553,594바이트였고 실패 증거 선택은 12 MiB 이내였다. 성공 모드 선택은 색인 추가 전 78,923바이트를 유지했다. 성공 모드 예시는 패키징 시뮬레이션이며, 해당 실패 CI 실행을 성공으로 다시 표시한 것이 아니다.
- 서브에이전트 리뷰는 사용할 수 없었고 수행했다고 주장하지 않았다. 같은 세션의 리뷰에서 모드 제한, 같은 실행 아티팩트 경로, 변경하지 않은 UI 실행 78개, 파일 제외와 새로운 청구·비밀 정보 쓰기가 없음을 확인했다.

## 동시 변경 조정

게시 전에 PR6은 7bccfccb3d3d2eeb4347defeea08015415fb95ad로 진행했다. 이 버전의 네이티브 선택기는 이미 정확한 HWND를 고정하며, 인쇄 포커스 변경도 보존해야 한다. 오래된 로컬 드라이버 수정은 게시하지 않는다. 가져온 더 새로운 드라이버(blob 8f4fe4d2da7ca0ccb94395900aba8452668bab9f)를 변경하지 않고 유지하며, 이 업데이트의 오류 대화상자 닫기용 정확한 HWND 헬퍼와 회귀 테스트도 보존한다. 명시적인 CI·워크플로·헬퍼·테스트·문서 변경만 트리 20dbeaf355315ba52bbc800d572ce2304c02c95f 위에 리베이스한다. 동시 인쇄 변경을 reset하거나 force-push하거나 교체하지 않는다.
